Since the release of Nitrocid 0.2.0 earlier this year, we have been working on adding new features while improving user experience across the whole Nitrocid operating system simulation program. We have done many important changes that we think are beneficial for both performance and reliability of Nitrocid and its components, and applied those concepts to several of our projects that we ship, including BassBoom.

Starting from today, Aptivi has announced that Nitrocid 0.2.1 has reached a point where a release candidate is now becoming ready after many reliability improvements made to both Nitrocid and Terminaux in consecutive months. We are very proud to announce that Nitrocid 0.2.1 Release Candidate will be available on **October 8th**, and that Terminaux 8.8 will be available on **October 1st**, to showcase the massive breakthrough that we've made during this year, from being stable to being more powerful.

## Features

Nitrocid 0.2.1 Release Candidate is built on top of the earlier technical preview version we've released on June, which shapes the foundation of what will eventually be the final version of Nitrocid 0.2.1 expected to be released this November.

### Improved The Nitrocid Homepage

![Improved TNH](/newsroom/images/nitrocid-0.2.1-rc/001.png)

We have improved The Nitrocid Homepage to incorporate a more fluid experience when the RSS feed is turned on. Now, instead of getting a blank screen when the RSS feeds from your favorite source are loading, you'll be immediately transported to the homepage while the feeds are still loading, giving you a more fluid experience that you've been waiting for since the homepage was built.

### Multiple feeds in RSS TUI

![RSS TUI](/newsroom/images/nitrocid-0.2.1-rc/002.png)

The textual user interface for the RSS reader has gained multiple advantages, including the ability to read articles from more than one RSS feed. You can add more than a single feed, and the RSS TUI will do the rest of the work. This way, you'll be able to get access to articles from different sites without exiting the TUI. You can also refresh all feeds to get more up-to-date news, especially for tech news.

### POP mail is back!

![RSS TUI](/newsroom/images/nitrocid-0.2.1-rc/003.png)

This is where it gets interesting. We removed POP mail as it caused Nitrocid to be unusable in ARM systems, but that was back when we supported Mono installations in Linux systems. As we took that out in Nitrocid 0.1.0 as part of modernization process, we wanted to bring POP mail back. However, due to unexpected events that happened, we weren't able to incorporate it to feature releases of Nitrocid. Now, we are so happy to announce that you can finally use POP mail!

## Availability

Nitrocid 0.2.1 Release Candidate will be available on **October 8th** on all platforms, including WinGet and Launchpad PPA.
